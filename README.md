# BAML-coursework

## 📖 Description
**Business Analytics and Machine Learning (BAML)** coursework.

This repository contains my exercises and assignments completed during the **Summer Semester of 2025**. The project tracks my learning progress and hands-on practice in data science and analytics.

---

## 🛠️ Tech Stack & Topics
The coursework covers the following foundational topics:

* **SQL**: Database querying, data manipulation, and relational database management.
* **Python**: Data analysis and programming logic.
* **Basic Machine Learning**: Introduction to predictive modeling and ML algorithms.
* **R Language**: Statistical analysis and data visualization (stored as `.ipynb` notebooks).

---

## 📂 How to View
The notes and assignments are primarily saved as `.ipynb` (Jupyter Notebook) files. 
* **On GitHub**: Simply click the files to view the rendered code and outputs directly in your browser.
* **Locally**: Download the files and open them using **JupyterLab** or **VS Code**.
